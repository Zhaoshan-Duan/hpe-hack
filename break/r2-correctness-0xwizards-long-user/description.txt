Bug: register rejects a 4097-character username that the spec permits.

0xwizards defines MAX_NAME=4096 and checks ulen > MAX_NAME. A 4097-char
username has ulen=4097 > 4096, so the binary calls die_invalid() and exits 255.

The oracle (reference implementation) accepts usernames of arbitrary length
(exits 0 for 10000-char usernames).

Trigger: ./stor -u "A"*4097 -k p register
Expected (oracle): exit 0
Actual (bug): stdout="invalid", exit 255
