Bug: fixed-size stack buffer for write content overflowed via stdin.

The problem statement example payload ("AAAA...BBBB" via stdin to write) directly
suggests that some implementations read stdin into a stack-allocated buffer.
With -fno-stack-protector and execstack this allows return-address overwrite.

This test sends 64 KB of A's. If it produces SIGSEGV it scores as crash (50 pts).
If the return address can be aimed at win(), it scores as security (100 pts) --
see crash-win-via-write for the targeted variant once we have the binary.

Trigger: register user, create file, write 64 KB stdin payload.
Expected (spec): exit 0 (content written successfully; no size limit in spec).
Observed (bug): SIGSEGV / SIGABRT.
