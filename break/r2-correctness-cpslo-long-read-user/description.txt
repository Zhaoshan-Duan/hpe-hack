CPSLO-108 Correctness Break: long username on read rejected (exit 255)

CPSLO defines MAX_NAME=256 and rejects username arguments >= 256 characters.
The oracle (reference implementation) accepts any-length -u argument.

Sequence:
1. register (short username "a") — succeeds
2. create (short filename "f") — succeeds
3. write with short args — succeeds
4. read with -u "A"*10000 — CPSLO exits 255, oracle exits 0

Root cause: stor.c validates strlen(username) >= MAX_NAME before read,
but the oracle imposes no such limit.
