Bug: empty string key is accepted by 'register' instead of being rejected
with exit 255.

Spec: -k requires a non-empty key. On any invalid argument, stor must print
'invalid' and exit 255.

Root cause: stor.c only checks strlen(key) > MAX_KEY_LEN (128), not
strlen(key) == 0, so an empty string key passes validation and a user is
registered with an empty password (exit 0, no output).

Trigger: register with -k '' (empty string key).
Expected (oracle): exit 255, stdout 'invalid'.
Actual (bug): exit 0, stdout ''.
