Bug: register with a 10000-character key exits 255 instead of 0.

Spec/oracle: keys of any length must be accepted (exit 0).
Root cause: stor.c:519 — op_register() rejects strlen(key) > MAX_KEY (1024).
Oracle has no such cap.

Trigger: register username "alice" with a 10000-char key.
Expected (oracle): exit 0.
Actual (bug): exit 255.
