CPSLO-108 Correctness Break: long filename on write rejected (exit 255)

CPSLO defines MAX_NAME=256 and rejects filename arguments >= 256 characters.
The oracle (reference implementation) accepts any-length -f argument.

Sequence:
1. register (short username/key) — succeeds
2. create (short filename) — succeeds
3. write with -f "A"*10000 — CPSLO exits 255, oracle exits 0

Root cause: stor.c validates strlen(filename) >= MAX_NAME before write,
but the oracle imposes no such limit.
