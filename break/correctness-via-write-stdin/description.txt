Bug: write command rejects stdin input, exiting 255 instead of reading from stdin.

The write command requires either a positional text argument or -i inputfile.
When invoked with only stdin (no text arg, no -i), parse_args() fails validation
at line 520: `if (!args->inputfile && !args->text) return 0;` and the binary
exits 255. The spec requires write to accept content via stdin.

Trigger: register, create file, write with stdin="hello" (no text arg, no -i flag).
Expected: write exits 0, subsequent read exits 0 and outputs "hello".
Actual: write exits 255 with "invalid\n".

Source: stor.c:519-521 (parse_args CMD_WRITE validation).
