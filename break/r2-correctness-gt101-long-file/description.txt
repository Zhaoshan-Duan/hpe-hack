Bug: create with a 10000-character filename exits 255 instead of 0.

Spec/oracle: filenames of any length must be accepted (exit 0).
Root cause: stor.c:407 — do_create rejects strlen(filename) > MAX_NAME_LEN (255).
Oracle has no such cap.

Trigger: register user "alice", then create a file with a 10000-char name.
Expected (oracle): both commands exit 0.
Actual (bug): create exits 255.
