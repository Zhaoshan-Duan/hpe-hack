Bug: register rejects a 256-character username that the spec permits.

stor.c defines MAX_NAME=256 and checks strlen(user) >= MAX_NAME.
A 256-char username has strlen=256 which is >= 256, so it returns "invalid"
exit 255.

The oracle accepts usernames of any length (exit 0).

Trigger: ./stor -u "a"*256 -k secret register
Expected (oracle): exit 0
Observed: stdout="invalid", exit 255
