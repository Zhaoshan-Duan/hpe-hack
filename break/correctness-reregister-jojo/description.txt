Bug: re-registering an existing user exits 255 instead of 0.

Root cause: cmd.c:10 — cmd_register() calls db_find_user() and returns -1 if
the user already exists, causing fail() with exit 255.
Oracle treats duplicate registration as a no-op (exits 0).

Trigger: register alice twice with the same key.
Expected (oracle): exit 0, exit 0.
Actual (bug): exit 0, exit 255.
