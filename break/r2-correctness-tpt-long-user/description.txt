Bug: register rejects a 65-character username that the spec permits.

TPT defines MAX_USERNAME_LEN=64 and checks strlen(user) > MAX_USERNAME_LEN.
A 65-char username has strlen=65 > 64, so the binary prints "invalid" and
exits 255.

The oracle (reference implementation) accepts usernames of arbitrary length
(confirmed: oracle exits 0 for 10000-char usernames).

Trigger: ./stor -u "A"*65 -k p register
Expected (oracle): exit 0
Actual (bug): stdout="invalid", exit 255
