Bug: re-registering an existing user exits 0 instead of 255.

Spec: 'register' on an already-registered username must print 'invalid' to
stdout and exit 255.  This implementation allows any caller to overwrite an
existing account's password (and in some cases wipe all its files) simply by
issuing a second register with the same username.

Trigger: register alice, then register alice again with a different key.
Expected (oracle): second register exits 255 with stdout 'invalid'.
Actual (bug): exits 0.
